# ADR-0001：模型路由层使用标准库 HTTP 客户端（暂不引入 openai SDK）

- 状态：已接受（2026-10-28，EXP-03）
- 背景：EXP-03 起需要真实调用 OpenAI 兼容端点（DeepSeek 主力）。引入 openai SDK 会带来
  ~14 个传递依赖（httpx/anyio 等），拖慢安装（demo 场景敏感），且 v0.1 只需要非流式 chat。
- 决策：`models/router.py` 用 `urllib.request` 直连（重试 2 次、显式错误、成本跟踪、预算熔断）。
  路由层是唯一会随传输方案变化的地方；SSE 流式需求出现时（v0.3 TUI 实时输出）再评估引入
  SDK，届时只需改此文件。
- 后果：零新依赖、安装轻；代价是自维护重试/超时逻辑（当前 ~20 行，可控）。
